## 归因分类

写法问题：

- 步骤包含分支决策。
- 前置塞入业务状态。
- 预期结果包含多个断言。
- UI 元素没有证据来源。

信息缺口：

- 缺账号或密码。
- 缺入口路径。
- 缺测试数据构造方式。
- 缺异常注入工具。
- 缺真实提示文案。

执行器边界：

- 需要真实支付。
- 需要真实 GPS / 人脸 / 指纹。
- 需要跨设备协作。
- 需要长时间真实等待。
