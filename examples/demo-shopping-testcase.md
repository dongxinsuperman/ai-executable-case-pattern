# 示例商城收藏功能 V1.0 测试用例

> 本示例由 [demo-shopping-feature-list.md](demo-shopping-feature-list.md) 转换而来。它展示的是公开 Demo 写法，不代表任何公司的内部业务规则。

- 示例商城收藏功能 V1.0 测试用例
  - 商品详情与收藏（P0）
    - 商品详情页收藏入口
      - 收藏商品
        - 测试标题：【正向】未收藏商品点击「收藏」后按钮变为「已收藏」
          - 前置条件：[起跑线]关闭 App「示例商城」（杀进程）后重新打开 App「示例商城」；若进入登录页则使用 demo_buyer_01/Demo@123 登录、若已自动登录则跳过登录；必须按照步骤一步步执行；[约束]仅测试环境；非业务弹窗允许自动关闭
            - 操作步骤：点击底部 Tab「首页」、在首页搜索框输入「Demo 蓝牙耳机」、点击搜索结果卡片「Demo 蓝牙耳机」、点击商品详情页标题下方「收藏」按钮
              - 预期结果：商品详情页标题下方按钮文案变为「已收藏」
        - 测试标题：【反向】已收藏商品点击「已收藏」后按钮恢复为「收藏」
          - 前置条件：[起跑线]关闭 App「示例商城」（杀进程）后重新打开 App「示例商城」；若进入登录页则使用 demo_buyer_01/Demo@123 登录、若已自动登录则跳过登录；必须按照步骤一步步执行；[约束]仅测试环境；非业务弹窗允许自动关闭
            - 操作步骤：点击底部 Tab「首页」、在首页搜索框输入「Demo 蓝牙耳机」、点击搜索结果卡片「Demo 蓝牙耳机」、点击商品详情页标题下方「收藏」按钮、点击商品详情页标题下方「已收藏」按钮
              - 预期结果：商品详情页标题下方按钮文案变为「收藏」
      - 收藏异常处理
        - 测试标题：【异常】收藏接口返回 500 时页面顶部显示失败 toast
          - 前置条件：[起跑线]关闭 App「示例商城」（杀进程）后重新打开 App「示例商城」；若进入登录页则使用 demo_buyer_01/Demo@123 登录、若已自动登录则跳过登录；通过网络代理工具将 POST /api/demo/favorites 响应改为 500；必须按照步骤一步步执行；[约束]仅测试环境；非业务弹窗允许自动关闭
            - 操作步骤：点击底部 Tab「首页」、在首页搜索框输入「Demo 蓝牙耳机」、点击搜索结果卡片「Demo 蓝牙耳机」、点击商品详情页标题下方「收藏」按钮
              - 预期结果：页面顶部显示「收藏失败，请稍后重试」toast

## 规则命中说明

- 所有 case 都从冷启动开始，保证起跑线一致。
- 所有输入值、按钮文案、商品名都来自 Feature List。
- 操作步骤为单线瀑布，不包含业务决策分支。
- 每条 case 只保留一个核心预期结果。
- 异常 case 写明了异常注入工具和接口。
